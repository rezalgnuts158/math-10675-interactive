Introducing the
difference quotient

From a secant slope to a symbolic rule. Build the quotient, simplify carefully, and keep its domain restrictions.

One interval. Two changes.

Average rate of change asks: what constant rate would produce the same output change over the same input change?

\(\displaystyle \frac{\Delta y}{\Delta x}=\frac{f(b)-f(a)}{b-a},\qquad a\ne b\)

Terri’s race · time as an output

Terri reaches kilometer 4 after 29 minutes and kilometer 8 after 57 minutes in a 10-kilometer race. Her pace changes along the course.

The curve is one possible sketch through the given data, not a measured formula for the whole race.

min/km

Worked answer
\(\displaystyle \frac{57-29}{8-4}=\frac{28}{4}=7\)

At a constant pace of 7 minutes per kilometer, Terri would take the same 28 minutes to cover these 4 kilometers.

min

Worked answer
\(\displaystyle 7(10-8)=14\)

This is additional time. The predicted total time is 57 + 14 = 71 minutes.

The vertical axis is minutes and the horizontal axis is kilometers. The slope is pace in min/km. Larger pace means more time per kilometer.

The output increases by about 1.156 over an input increase of 7.

The negative rate records a decrease of 7.5 in the output over an input increase of 3.

From two endpoints to a difference quotient

Start at \(x\), move by \(h\), and arrive at \(x+h\).

\(\displaystyle \Delta x=(x+h)-x=h\)
\(\displaystyle \Delta f=f(x+h)-f(x)\)
\(\displaystyle D_f(x,h)=\frac{f(x+h)-f(x)}h\)

Require \(h\ne0\) and both \(x\) and \(x+h\) in the domain of \(f\).

Keep the same subtraction order

5. Write the average rate of a function \(d\) from 4 to 7.

Worked answer
\(\displaystyle \frac{d(7)-d(4)}{7-4}=\frac{d(7)-d(4)}3\)
6. A generic function g: from −3 to 0
\(\displaystyle \frac{g(0)-g(-3)}{0-(-3)}=\frac{g(0)-g(-3)}3\)

Here \(g\) is a generic function defined at both inputs; it is not the preceding \(10/x\) example, which is undefined at zero.

7. From n to n + 2
\(\displaystyle \frac{f(n+2)-f(n)}{(n+2)-n}=\frac{f(n+2)-f(n)}2\)

What can h mean?

It is a signed input change, not a fixed number or a function value. If \(h<0\), the second input is to the left.

\(\displaystyle \frac{f(x+h)-f(x)}h=\frac{f(x)-f(x+h)}{-h}\)

Reversing both subtraction orders leaves the same slope.

Can you use h = 0 after canceling h?

Worked answer

Canceling simplifies values for \(h\ne0\). The formula may have an extension to zero, but that extension is not the original quotient at zero.

Exercise 8 · The quadratic bridge

For \(f(x)=\tfrac12x^2+3\), reveal each algebra step.

  1. Substitute the entire new input

    \(\displaystyle f(x+h)=\tfrac12(x+h)^2+3\)

    Replace every occurrence of the input variable by the parenthesized expression \(x+h\). Do not add \(h\) to the output.

  2. Build the quotient before simplifying

    \(\displaystyle \frac{f(x+h)-f(x)}h=\frac{[\tfrac12(x+h)^2+3]-[\tfrac12x^2+3]}h\)

    Keep brackets around the whole expression being subtracted.

  3. Expand and distribute the subtraction

    \(\displaystyle =\frac{\tfrac12x^2+xh+\tfrac12h^2+3-\tfrac12x^2-3}h\)
    \(\displaystyle =\frac{xh+\tfrac12h^2}h\)

  4. Factor the whole numerator, then cancel

    \(\displaystyle =\frac{h(x+\tfrac12h)}h=x+\tfrac12h,\qquad h\ne0\)

    The cancellation uses a nonzero common factor. The original quotient is still undefined at \(h=0\).

Worked answer
\(\displaystyle \Delta x=0.5,\quad\Delta f=6.125-5=1.125\)
\(\displaystyle \frac{1.125}{0.5}=2.25=2+\tfrac12(0.5)\)
Making \(|h|\) smaller compares closer inputs. For this smooth function, the secant slopes approach the local rate. Keep \(h\) nonzero while computing each quotient.

Rational functions: combine fractions first

The main algebra task is in the numerator: subtract two fractions correctly. Once that difference is a single fraction, factor and cancel.

Example A · \(g(x)=10/x\)

  1. Record the restrictions first

    \(\displaystyle g(x)=\frac{10}{x},\quad x\ne0\)
    \(\displaystyle h\ne0,\quad x\ne0,\quad x+h\ne0\)

    The second function value has its own denominator. Check it as well as the first.

  2. Substitute x + h in the denominator

    \(\displaystyle g(x+h)=\frac{10}{x+h}\)

    \(g(x+h)\ne\frac{10}{x}+h\). The whole new input replaces \(x\).

  3. Build the complex fraction

    \(\displaystyle \frac{g(x+h)-g(x)}h=\frac{\frac{10}{x+h}-\frac{10}{x}}h\)

    There are two levels of division: first subtract the function values, then divide their difference by \(h\).

  4. Give the numerator a common denominator

    \(\displaystyle \frac{10}{x+h}-\frac{10}{x}=\frac{10x}{x(x+h)}-\frac{10(x+h)}{x(x+h)}\)
    \(\displaystyle =\frac{10x-10(x+h)}{x(x+h)}\)

    Multiply the first fraction by \(x/x\) and the second by \((x+h)/(x+h)\). Keep the second numerator in parentheses.

  5. Distribute the minus sign

    \(\displaystyle 10x-10(x+h)=10x-10x-10h=-10h\)

    The minus sign changes both terms in \(10(x+h)\).

  6. Divide by h by multiplying by 1/h

    \(\displaystyle \frac{\frac{-10h}{x(x+h)}}h=\frac{-10h}{x(x+h)}\cdot\frac1h=\frac{-10h}{hx(x+h)}\)

    Dividing the fraction by \(h\) puts an extra factor of \(h\) in its denominator.

  7. Cancel the common nonzero factor

    \(\displaystyle D_g(x,h)=-\frac{10}{x(x+h)}\)
    \(\displaystyle h\ne0,\quad x\ne0,\quad x+h\ne0\)

    Cancel the factor \(h\), never a term inside a sum such as \(x+h\). Carry all three restrictions into the final answer.

  8. Verify with two actual inputs

    \(\displaystyle x=1,\quad h=3,\quad x+h=4\)
    \(\displaystyle \frac{g(4)-g(1)}3=\frac{2.5-10}3=-2.5\)
    \(\displaystyle -\frac{10}{1(1+3)}=-2.5\)

    The original and simplified expressions match.

Example B · A variable in both numerator and denominator

Use \(r(x)=\frac{2x+1}{x-3}\) to practice parentheses and cancellation of matching products.

  1. Substitute and retain both denominators

    \(\displaystyle r(x)=\frac{2x+1}{x-3},\qquad r(x+h)=\frac{2x+2h+1}{x+h-3}\)
    \(\displaystyle h\ne0,\quad x\ne3,\quad x+h\ne3\)

  2. Combine the function values over a common denominator

    \(\displaystyle \frac{r(x+h)-r(x)}h=\frac{(2x+2h+1)(x-3)-(2x+1)(x+h-3)}{h(x+h-3)(x-3)}\)

    Cross-multiply the numerators. Subtract the entire second product.

  3. Expose the matching products before expanding

    \(\displaystyle 2x+2h+1=(2x+1)+2h\)
    \(\displaystyle x+h-3=(x-3)+h\)
    \(\displaystyle N=(2x+1)(x-3)+2h(x-3)-(2x+1)(x-3)-h(2x+1)\)

    The identical products cancel; \(N\) denotes the numerator.

  4. Factor h and simplify its coefficient

    \(\displaystyle N=h[2(x-3)-(2x+1)]\)
    \(\displaystyle =h(2x-6-2x-1)=-7h\)

  5. Cancel and retain the original domain conditions

    \(\displaystyle D_r(x,h)=-\frac7{(x+h-3)(x-3)}\)
    \(\displaystyle h\ne0,\quad x\ne3,\quad x+h\ne3\)

    Check: at \(x=4,h=1\), \(r(5)=11/2\) and \(r(4)=9\), so both methods give \(-7/2\).

A reusable plan for any rational function

\(\displaystyle R(x)=\frac{P(x)}{Q(x)}\)
\(\displaystyle D_R(x,h)=\frac{P(x+h)Q(x)-P(x)Q(x+h)}{hQ(x+h)Q(x)}\)
  1. Require \(h\ne0\), \(Q(x)\ne0\), and \(Q(x+h)\ne0\).
  2. Substitute \(x+h\) in every part of both polynomials.
  3. Form the two cross-products and subtract with brackets.
  4. Simplify the entire numerator; factor out \(h\).
  5. Cancel only common factors and keep the restrictions.
Optional pattern · a linear numerator and denominator
\(\displaystyle R(x)=\frac{ax+b}{cx+d}\quad\Longrightarrow\quad D_R(x,h)=\frac{ad-bc}{(cx+d)(c(x+h)+d)}\)

The cross-product numerator reduces to \((ad-bc)h\). This formula is valid wherever both denominators are nonzero and \(h\ne0\). It also covers the constant case \(ad-bc=0\) on the original domain.

A finite secant slope needs two defined endpoint values. To interpret it as a rate through an entire interval, also check that the function is defined between them; a vertical asymptote breaks that interval.

Cubic functions: expand, subtract, factor

Keep the whole original function inside brackets until you distribute the subtraction. Expand the cube completely, then look for a common factor of h.

Example A · The basic cube

  1. Substitute before expanding

    \(\displaystyle f(x)=x^3\quad\Longrightarrow\quad f(x+h)=(x+h)^3\)
    \(\displaystyle D_f(x,h)=\frac{(x+h)^3-x^3}h,\quad h\ne0\)

  2. Build the cube from multiplication

    \(\displaystyle (x+h)^3=(x+h)(x^2+2xh+h^2)\)
    \(\displaystyle =x^3+2x^2h+xh^2+x^2h+2xh^2+h^3\)
    \(\displaystyle =x^3+3x^2h+3xh^2+h^3\)

    The middle terms are essential. In particular, \((x+h)^3\ne x^3+h^3\).

  3. Subtract the original function

    \(\displaystyle D_f(x,h)=\frac{x^3+3x^2h+3xh^2+h^3-x^3}h\)
    \(\displaystyle =\frac{3x^2h+3xh^2+h^3}h\)

  4. Factor the entire numerator

    \(\displaystyle =\frac{h(3x^2+3xh+h^2)}h\)

    Each term has at least one factor of \(h\). Taking out \(h\) lowers its exponent in every term by one.

  5. Cancel and verify

    \(\displaystyle D_f(x,h)=3x^2+3xh+h^2,\quad h\ne0\)
    \(\displaystyle x=2,\ h=1:\quad\frac{3^3-2^3}1=19\)
    \(\displaystyle 3(2)^2+3(2)(1)+1^2=19\)

    All real \(x\) are allowed; only \(h=0\) is excluded.

Alternative method · difference of cubes
\(\displaystyle A^3-B^3=(A-B)(A^2+AB+B^2)\)
\(\displaystyle (x+h)^3-x^3=h[(x+h)^2+x(x+h)+x^2]\)
\(\displaystyle \frac{(x+h)^3-x^3}h=(x+h)^2+x(x+h)+x^2=3x^2+3xh+h^2\)

Example B · A full cubic polynomial

  1. Substitute x + h everywhere

    \(\displaystyle p(x)=2x^3-3x^2+4x-5\)
    \(\displaystyle p(x+h)=2(x+h)^3-3(x+h)^2+4(x+h)-5\)

  2. Subtract the whole original polynomial

    \(\displaystyle D_p(x,h)=\frac{2(x+h)^3-3(x+h)^2+4(x+h)-5-[2x^3-3x^2+4x-5]}h\)

    The final bracket becomes \(-2x^3+3x^2-4x+5\). Every sign changes.

  3. Expand powers and distribute coefficients

    \(\displaystyle 2(x+h)^3=2x^3+6x^2h+6xh^2+2h^3\)
    \(\displaystyle -3(x+h)^2=-3x^2-6xh-3h^2\)
    \(\displaystyle 4(x+h)=4x+4h\)

  4. Combine and cancel only matching terms

    \(\displaystyle p(x+h)-p(x)=6x^2h+6xh^2+2h^3-6xh-3h^2+4h\)

    The terms involving only \(x\) and the constants cancel. Every remaining term contains \(h\).

  5. Factor, divide, and state the restriction

    \(\displaystyle p(x+h)-p(x)=h(6x^2+6xh+2h^2-6x-3h+4)\)
    \(\displaystyle D_p(x,h)=6x^2+6xh+2h^2-6x-3h+4,\quad h\ne0\)

    Check \(x=1,h=2\): \([p(3)-p(1)]/2=(34-(-2))/2=18\). The simplified expression also gives 18.

A pattern you can justify term by term

\(\displaystyle p(x)=ax^3+bx^2+cx+d\)
\(\displaystyle D_p(x,h)=a(3x^2+3xh+h^2)+b(2x+h)+c,\quad h\ne0\)

The constant \(d\) cancels. The linear part contributes \(c\). The quadratic and cubic parts contribute their own difference quotients.

Do not drop the terms containing \(h\) when you are asked for the difference quotient. For a finite nonzero \(h\), those terms are part of the answer. Discussing what happens as \(h\) approaches zero is a separate step.

For \(\tfrac12x^2+3\), the quotient is \(x+\tfrac12h\), so at \(x=2\) it approaches 2 as \(h\) approaches zero. For \(x^3\) at the same starting input, it approaches 12. Neither original quotient permits \(h=0\).

Practice: work it out before checking

Eight questions move from substitution to complete rational and cubic quotients. Show your algebra on paper, then check your result. Numeric answers accept decimals or fractions.

0 of 8 practice questions correct.

01 · New input

For \(f(x)=3/(x-2)\), which is \(f(x+h)\)?

Worked answer

Replace the input \(x\) by \(x+h\) in the entire denominator.

02 · Common denominator

Combine \(\frac5{x+h}-\frac5x\) into one fraction.

Worked answer
\(\displaystyle \frac{5x-5(x+h)}{x(x+h)}=\frac{-5h}{x(x+h)}\)

This is the output difference; dividing by \(h\) is still a separate operation.

03 · Rational quotient

Simplify the difference quotient for \(f(x)=3/(x-2)\).

Worked answer
\(\displaystyle \frac{\frac3{x+h-2}-\frac3{x-2}}h=\frac{3(x-2)-3(x+h-2)}{h(x+h-2)(x-2)}\)
\(\displaystyle =\frac{-3h}{h(x+h-2)(x-2)}=-\frac3{(x+h-2)(x-2)}\)

Require \(h\ne0,\ x\ne2,\ x+h\ne2\).

04 · Keep all restrictions

For the quotient in Question 3, which restrictions are required?

Worked answer

The outer denominator requires \(h\ne0\). The two function values require \(x\ne2\) and \(x+h\ne2\). Cancellation does not remove these restrictions.

05 · Rational with two variable expressions

Calculate the difference quotient for \(r(x)=(x+2)/(x-1)\).

Worked answer
\(\displaystyle N=(x+h+2)(x-1)-(x+2)(x+h-1)\)
\(\displaystyle =h(x-1)-h(x+2)=-3h\)
\(\displaystyle D_r(x,h)=-\frac3{(x+h-1)(x-1)}\)

Require \(h\ne0,\ x\ne1,\ x+h\ne1\).

06 · Cubic substitution

For \(f(x)=x^3-2x\), find the difference quotient.

Worked answer
\(\displaystyle f(x+h)-f(x)=3x^2h+3xh^2+h^3-2h\)
\(\displaystyle D_f(x,h)=3x^2+3xh+h^2-2,\quad h\ne0\)

The middle terms in the cube do not vanish. Factor \(h\) out of all four terms.

07 · Cubic with negative h

Worked answer
\(\displaystyle \frac{f(1.5)-f(2)}{-0.5}=\frac{3.375-8}{-0.5}=9.25\)
\(\displaystyle 3(2)^2+3(2)(-0.5)+(-0.5)^2=9.25\)

08 · Full cubic

Find the difference quotient for \(p(x)=2x^3+x^2-5x+7\).

Worked answer
\(\displaystyle p(x+h)-p(x)=6x^2h+6xh^2+2h^3+2xh+h^2-5h\)
\(\displaystyle D_p(x,h)=6x^2+6xh+2h^2+2x+h-5,\quad h\ne0\)

The constant 7 cancels; the linear term contributes −5.

Exit check · diagnose the mistake

A student writes \([(x+h)^3-x^3]/h=h^2\). What did they omit?

Compare your explanation

The student used the false identity \((x+h)^3=x^3+h^3\). The missing terms are \(3x^2h+3xh^2\). The correct quotient is \(3x^2+3xh+h^2\), with \(h\ne0\).
