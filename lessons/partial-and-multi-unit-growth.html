Investigation 4 · Develop the idea

Build a factor for any interval

Start with a known factor and interval. Use roots and powers to find the multiplier for a different interval.

A factor for any interval

Why the exponent is a ratio of intervals

  1. A known interval of length \(h\) changes the output by factor \(B\).
  2. A one-unit factor \(b\) must satisfy \(b^h=B\), so \(b=B^{1/h}\).
  3. An interval of length \(\Delta x\) has factor \(b^{\Delta x}=B^{\Delta x/h}\).

Convert interval lengths before converting to percent change.

\(\text{factor}=B^{\Delta x/h}\)

\(\text{signed percent change}=100(B^{\Delta x/h}-1)\%\).

Assume a positive exponential model with \(B>0\) and \(h>0\). The graph uses \(F(x)=B^{x/h}\), with initial value \(1\). Its ratio does not depend on where the interval starts.

Half of a doubling interval needs factor \(\sqrt2\), because \(\sqrt2\cdot\sqrt2=2\). Dividing the factor by two would give \(1\), which produces no growth.

Roots and exponent rules

For positive bases, \(b^{p/q}=(\sqrt[q]{b})^p\), with positive integer \(q\). Thus \(9^{1/2}=3\), \(121^{1/2}=11\), and \(4^{3/2}=8\).

\(a^2a^4=a^6\), \(b^7/b^2=b^5\) for \(b\ne0\), and \((c^2)^5=c^{10}\).

Distinguish a principal root from solving an equation: \(\sqrt{81}=9\), but \(x^2=81\) has solutions \(x=\pm9\). Also, \(x^3=27\) gives \(3\), \(x^{3/4}=8\) gives \(16\), and \(x^{1/5}=2\) gives \(32\).

Change the time scale

One model, several equivalent formulas

The exponent counts known intervals. If \(t\) is elapsed time and the known factor applies over \(h\) time units, use

\(F(t)=F(0)B^{t/h}\).

For the alpacas, keeping the original ratio gives \(A(t)=218(187/218)^{t/8}\). If \(k\) measures months, the same model is \(A(k)=218(187/218)^{k/96}\).

A half-life is an interval that multiplies any current amount by \(1/2\). The same interval takes \(218\) to \(109\) and \(120\) to \(60\).

These are the investigation’s mathematical models. Counts are model estimates; continuing a model beyond the stated observations is an extrapolation. Calculations here retain the exact ratio \(187/218\), so small differences from the source’s rounded factors are expected.

Reveal the model and interval reasoning

The base is not always the one-unit factor

For \(g(x)=0.46(0.874)^{4x}\), a one-unit change in \(x\) changes the exponent by \(4\). Therefore the one-unit factor is \(0.874^4\). The base \(0.874\) is the quarter-unit factor.

From two positive outputs, first find the gap and ratio:

\(h=x_2-x_1,\quad B=\dfrac{y_2}{y_1}\).

Then \(b=B^{1/h}\), \(a=y_1/b^{x_1}\), and \(F(x)=ab^x\).

An equivalent anchored model is \(F(x)=y_1B^{(x-x_1)/h}\). This avoids rounding the initial value too early.

The classmate’s mistake (I4)

An exponential growth function contains \((4,38)\) and \((7,50)\). A classmate inserts \((5,42)\) and \((6,46)\) by adding \(4\) each time.

Those equal differences describe a line. An exponential model instead uses the same ratio \((50/38)^{1/3}\) for every one-unit step. Select this example to compare both sets of intermediate values.

Investigation 5 · Graphs

Separate a factor from a rate

Compare output ratios with secant slopes on the same graph.

Ratio and slope on the same graph

Green: exponential curveOrange: line joining endpoints

Two different comparisons

Growth or decay factor: \(F(v)/F(u)\), a ratio with no units when the outputs have the same unit.

Average rate of change: \(\dfrac{F(v)-F(u)}{v-u}\), measured in output units per input unit.

Hold the interval width fixed and move its starting point. The exponential factor stays the same, but the average rate changes.

The secant line has a constant slope that would produce the same total output change over this interval. The curve itself does not have that constant rate throughout the interval.

For the growth graph, the given points are \((-1,15.625)\) and \((1,40)\). Their ratio is \(2.56\); their average rate is \(12.1875\). These numbers answer different questions.

For the decay graph, the labeled output \(36.84\) is rounded. This tool fits those displayed points exactly using \(60(36.84/60)^{x/3}\), whose one-unit factor is approximately \(0.85\).

Investigation 5 · Applications

Interpret growth and decay in context

Work with population and caffeine models, keeping the time interval attached to every factor.

Compare time intervals

Start with what remains or what is attained

If a quantity decreases by \(p\%\), its factor is \(1-p/100\). For a \(27\%\) decrease over four hours, use factor \(0.73\) over that interval.

The one-hour factor is \(0.73^{1/4}\). A full day has six four-hour periods, so the daily factor is \(0.73^6\).

Always label the interval attached to a factor or percentage.

\(F(t)=aB^{t/h}\) uses \(t\) and \(h\) measured in the same units.

The population-data model uses millions of people; the caffeine model uses the fraction of the starting amount, since no initial mass is supplied.

The population figures are source-exercise data and assumptions, not a claim about present-day statistics. Source factors are rounded for display; the tools use the full ratios.
