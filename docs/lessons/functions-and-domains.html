The original box scenario

Cut equal squares of side length \(x\) inches from the corners of an \(8.5\)-inch by \(11\)-inch sheet, then fold up the sides. Let \(f\) give the box’s volume in cubic inches.

\(f(x)=x(11-2x)(8.5-2x)\)

A function assigns exactly one output to each input in its domain.

\(f\) names the function. \(x\) is an input. \(f(x)\) is the corresponding output; it does not mean \(f\) multiplied by \(x\).

Read \(f(1.5)\) as “f of one point five.” It names the volume of the box with a \(1.5\)-inch cutout, even before you compute that volume.

Domain, range, and rule

A square has side length \(s\) inches and perimeter \(P\) inches. Its perimeter cannot exceed \(48\) inches. Write \(P=f(s)=4s\).

Domain: allowed input values.

Range: output values actually produced.

Rule: how each input determines its unique output.

First use the context: \(s\ge 0\). Then use the perimeter limit: \(4s\le 48\), so \(s\le12\).

\(D=[0,12],\qquad R=[0,48]\)

For positive-size squares only, the corresponding intervals are \((0,12]\) and \((0,48]\). Always state whether a limiting case is included.

Read the tortoise’s lead

The viewing window is \(0\le t\le8\). It does not specify when the race ends. The lead formula alone does not give either runner’s individual speed or the race’s finishing time.

Intercepts have meanings

In a \(100\)-meter race, the tortoise’s signed lead over the hare is \(h(t)=39-6.5t\) meters, where \(t\) is seconds since the start. A positive lead means the tortoise is ahead; a negative lead means the hare is ahead.

The source uses \(x\) for time. Here we use \(t\) to make the units easier to follow.

Vertical intercept: set the input to zero. \((0,h(0))=(0,39)\) means a starting lead of \(39\) m.

Horizontal intercept: set the output to zero. \(39-6.5t=0\) gives \(t=6\), so the point is \((6,0)\). The hare has caught up.

Interpret \(h(7)=-6.5\).

Explain this domain and range

Find the allowed inputs first

  1. Start with real inputs. A polynomial has no algebraic input restriction.
  2. Denominators must be nonzero. Solve for the forbidden inputs.
  3. Even-root radicands must be nonnegative. If the root is in a denominator, it must be strictly positive.
  4. Meet every condition at once. Then apply any limits from the context.

Parentheses exclude an endpoint; brackets include it. Infinity always uses a parenthesis. The symbol \(\cup\) joins separate allowed intervals.

For \(g(x)=1/(x^2-9)\), which inputs are forbidden?

What is the domain of \(k(x)=\sqrt{x-2}/(x-9)\)?

Which is the range of \(g(x)=1/(x^2-9)\)?

A correction to the instructor notes

The notes list all nonzero real numbers as the range of \(1/(x^2-9)\). The correct range is \((-\infty,-\tfrac19]\cup(0,\infty)\). For example, \(-1/10\) is impossible: \(1/(x^2-9)=-1/10\) would imply \(x^2=-1\).

Read domain and range from a graph

The domain is the collection of horizontal coordinates reached by the graph. The range is the collection of vertical coordinates reached.

Drag your attention horizontally to read inputs and vertically to read outputs. Gaps matter: do not fill in intervals where no points exist.

The horizontal segment contributes a whole interval to the domain but only one value, \(\{-3.5\}\), to the range. That value remains in the range even when both endpoints are open, because interior points still have that height.
