Percent change &
exponential behavior

Compare amounts, build multipliers, and discover what distinguishes linear change from exponential change.

Percent of what?

A percentage compares a quantity with a reference amount. One percent means one hundredth of that reference amount.

A 25% tip on a $60 meal is 25 hundredths of $60. The percentage tells us a proportion; the reference amount determines the dollars.
\(\displaystyle \frac{25}{100}(60)=0.25(60)=15\)

Resize the reference amount

Both bars use the same scale. A percentage above 100% gives an amount larger than the reference.

Name the measurement

“Twenty-five hundredths” explains the decimal 0.25. Multiplication by 0.25 finds one quarter of the reference quantity.

Always complete the phrase: percent of what? The same percentage of different reference amounts gives different quantities.

Compare proportions, not just counts

Suppose 3.5 million of 12 million people in one country and 5.2 million of 65 million in another meet a given condition. Which country has the larger proportion?

Worked answer
\(\displaystyle \frac{3.5}{12}\cdot100\%\approx29.17\%,\qquad \frac{5.2}{65}\cdot100\%=8\%\)

The first country has fewer people in the category but a larger percentage of its population.

From percent change to a multiplier

Measure a change relative to the starting value. For the positive quantities in this lesson, a decrease gives a negative percent change.

\(\displaystyle \text{Percent change}=\frac{\text{new}-\text{old}}{\text{old}}\cdot100\%\)
\(\displaystyle \text{New value}=\text{old value}\left(1+\frac{p}{100}\right)\)

Here \(p\) is the signed percentage number; for a 40% decrease, use \(p=-40\). The starting value must be nonzero.

Repeat the factor

Each period starts with the previous period’s ending value. The percentage stays the same, while its reference amount changes.

A company doubles its number of employees every month. Each month’s total is 200% of the previous month’s total: a 100% increase.

Build repeated growth or decay

Start with 20 units. Choose a percentage change and count the periods.

This tool uses whole periods. The decay example models a continuous quantity; employee counts are whole numbers.

From repeated steps to an exponent

\(\displaystyle 20\longrightarrow20b\longrightarrow20b^2\longrightarrow20b^3\)
\(\displaystyle y=ab^t,\qquad b=1+\frac p{100}\)

\(a\) is the value at time zero. \(b\) is the multiplier per period. \(t\) counts those periods.

For positive \(a\): \(b>1\) gives growth; \(0<b<1\) gives decay. At \(b=1\), the value is constant.

Where does the linear resale model stop making sense?
\(\displaystyle 300-45t=0\quad\Longrightarrow\quad t=\frac{20}{3}\approx6.67\)

After about 6.67 years, this formula predicts a negative resale value. A nonnegative resale interpretation restricts it to \(0\le t\le20/3\). The exponential model stays positive for every finite \(t\ge0\); neither formula guarantees real-world values indefinitely.

Ratios versus differences

\(\displaystyle \frac{f(t+h)}{f(t)}=0.7^h\)
\(\displaystyle f(t+h)-f(t)=f(t)(0.7^h-1)\)

For fixed \(h\), the ratio is independent of \(t\), but the dollar change depends on the starting value \(f(t)\).

\(\displaystyle \frac{g(t+h)-g(t)}{h}=-45\qquad(h\ne0)\)

The linear model’s average rate is always −45 dollars per year. Its percentage loss is not constant.

For positive, nonconstant values: equal input changes with equal output differences indicate linear behavior; equal input changes with equal output ratios indicate exponential behavior. A constant function is the special case with zero change and ratio 1.

Exit check · constant percent, changing dollars

A student says, “iTech loses 30% each year, so it loses $90 every year.” Explain the mistake using the first two years.

Compare your explanation

The first year loses 30% of $300, or $90. The second year loses 30% of $210, or $63. The percentage is fixed, but it acts on a smaller reference amount. The yearly dollar changes are different, so the function does not have a constant rate of change.
