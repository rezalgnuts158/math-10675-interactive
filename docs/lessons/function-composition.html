Function composition

Chain two function processes. Identify the middle quantity, follow an input, and build a new rule.

Find the middle quantity

One function’s output can become another function’s input. First identify the quantities, then connect their rules.

Bob runs at a pace of 6 minutes per mile. In this exercise, the drink plan assigns 3 fluid ounces for each mile run. How can running time determine the amount of fluid?

Worked answer

Time determines distance in miles; distance determines fluid amount.

Follow a value through two processes

The slider shows 0–120 minutes. The mathematical model uses any nonnegative time.

Connect the quantities to notation
\(\displaystyle f(t)=\frac{t}{6}=d,\qquad g(d)=3d=n\)
\(\displaystyle h(t)=g(f(t))=3\left(\frac{t}{6}\right)=\frac{t}{2},\quad t\ge0\)

Read from the inside out: first use time in f, then use the resulting distance in g. The composite links minutes directly to ounces.

Match the units: minutes → miles → ounces. The output quantity of the first process must match the input quantity of the next.

Perimeter → side length → area

To find a square’s area from its perimeter, first recover a side length. This is the middle quantity.

Grow and shrink the square

For a genuine square, perimeter and side length are positive. Zero gives a degenerate limiting shape.

Build the composite

\(\displaystyle g(P)=\frac P4,\qquad h(x)=x^2\)
\(\displaystyle A=h(g(P))=\left(\frac P4\right)^2=\frac{P^2}{16},\quad P>0\)
Square the entire quotient: the denominator becomes 16.

Worked answer
\(\displaystyle \left(\frac P4\right)^2=\frac P4\cdot\frac P4=\frac{P^2}{16}\)

Substitute the whole inner output

Composition means one function after another. It does not mean multiplication, and reversing the order usually changes the result.

The source functions

\(\displaystyle f(x)=\sqrt{x+3},\qquad g(x)=2x+9,\qquad h(x)=\frac x4\)

1. Identify the inside function.

2. Find its output or formula.

3. Substitute that entire result into the outside function.

4. Check that both steps are defined.

Worked example: f(g(2))
\(\displaystyle g(2)=2(2)+9=13\)
\(\displaystyle f(g(2))=f(13)=\sqrt{13+3}=4\)

Compose the functions

Order and domain matter

\(\displaystyle f(g(x))=\sqrt{2x+12},\quad x\ge-6\)
\(\displaystyle g(f(x))=2\sqrt{x+3}+9,\quad x\ge-3\)

In the first expression, the square root acts on the output of the linear function. In the second, the square root acts on the original input.

\(\displaystyle \operatorname{Dom}(f\circ g)=\{x\in\operatorname{Dom}(g):g(x)\in\operatorname{Dom}(f)\}\)

Check the first function’s domain, then ensure its output is allowed into the next function.

The symbol \(\circ\) means composition. It is different from the multiplication dot \(\cdot\).

Exit check · diagnose the mistake

A student writes \(f(g(x))=f(x)g(x)\). Explain the difference using an input of your choice.

One way to explain

If \(f(x)=x+1\) and \(g(x)=2x\), then at \(x=2\), \(f(g(2))=f(4)=5\) but \(f(2)g(2)=3\cdot4=12\). Composition passes an output into a second function; multiplication multiplies two outputs.
